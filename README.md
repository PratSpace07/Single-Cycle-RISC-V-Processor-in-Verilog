# Single-Cycle-RISC-V-Processor-in-Verilog
A single-cycle RISC-V processor implemented in Verilog, featuring a five-stage datapath: Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB). The repository includes the processor design, a separate testbench, and a memory initialization file for loading machine instructions.
